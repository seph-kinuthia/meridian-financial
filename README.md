# Enwealth Financial Services

A premium, responsive redesign populated from Enwealth's published source content and built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown by Vite (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

Verified company, fund, regulatory and performance data should replace every clearly labelled placeholder before production use.
